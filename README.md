# 📱 MindTrade

**MindTrade** es una aplicación móvil desarrollada en **Android Studio** para ayudar a los traders a gestionar sus operaciones y estrategias.  
Este proyecto fue creado como parte de mi **fin de ciclo en Desarrollo de Aplicaciones Multiplataforma (DAM)**.

---

## 🚀 Características
- Registro de operaciones en mercados financieros.
- Gestión de estrategias de trading.
- Cálculo automático de ganancias y pérdidas.
- Interfaz sencilla y amigable.
